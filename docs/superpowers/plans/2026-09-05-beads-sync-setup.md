> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Configure this repository to use a Git-tracked, Dolt-backed Beads database that syncs across the owner’s machines, with reliable hooks and a reusable setup playbook.

**Architecture:** Initialize Beads in embedded Dolt mode with the stable `wilberwiki` issue prefix and the repository’s SSH origin as its Dolt remote. Track portable Beads metadata/configuration and JSONL export, ignore machine-local database/runtime files, and use repo-local hooks to pull after Git updates and push alongside Git pushes.

**Tech Stack:** `bd` 1.1.2, embedded Dolt, Git hooks, Markdown documentation.
