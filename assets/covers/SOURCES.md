# Cover image sources

All cover images in this folder were fetched from the [Open Library](https://openlibrary.org)
Covers API (`covers.openlibrary.org`), which serves scans contributed via the Internet
Archive's Open Library project. Fetched at "L" (large) size — a few hundred px on the long
edge, good enough for a works-grid thumbnail, not print quality. Re-fetch at a different
size by swapping `-L.jpg` for `-M.jpg` or `-S.jpg` (or higher-res by pulling the original
scan from the Internet Archive item, where available) if a better copy is needed later.

Not legal/licensing advice — these are publisher cover images used here for identification
purposes (a standard, widely accepted fair-use case for book covers on a reference/wiki
page about the books themselves), not redistributed as standalone artwork.

manual scan):

- Wicked and Wise (2015) — entry exists, no cover image indexed.
- Integral Meditation (2016) — entry exists, no cover image indexed.
- Trump and a Post-Truth World (2017) — only a third-party "book summary" product turns
  up, not the real book; not used.
- Integral Politics (2018, ebook)

- Finding Radical Wholeness (2024) — too recent, not yet catalogued.
