# Chart Index

*Integral Psychology*'s appendix is, by page count, most of the book: roughly twenty
correlation charts cross-indexing over a hundred developmental models against Wilber's
own scale. In the source they're scanned page images — legible, but locked in a
two-column print layout that splits every wide table across a page break. The pages
here redraw each chart as a proper web table: one page per logical chart (not per
scanned page-image), with each source page's sub-tables reconstructed in full.

Sourced entirely from *[Integral Psychology](../works/2000-integral-psychology.md)*
(`library/2000-integral-psychology-full-text.md`, backmatter). Transcribed and
cross-checked against the source page images
(`library/2000-integral-psychology-images/`); all pages are `status: draft` — first-pass
transcriptions, not yet independently re-verified. See
[`docs/integral-psychology-import-design.md`](../docs/integral-psychology-import-design.md)
for the reconstruction approach and its open questions.
