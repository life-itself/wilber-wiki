# Chart 3: Cognitive Development

Ten cognitive-development researchers correlated against the basic-structures spine,
including Piaget's own stages with average ages of emergence, three researchers'
own numbered sequences (Commons & Richards, Kurt Fischer with ages, Alexander), and
five more theorists (Pascual-Leone, Koplowitz, Arlin, Labouvie-Vief, Sinnott,
Basseches) — the last five run alongside Aurobindo's own terms for the spine, which map
1:1 onto the basic structures (see [Chart 2](chart-2-basic-structures-in-other-systems.md)).

Transcribed and cross-checked against the source page images
(`library/2000-integral-psychology-images/00024.jpg`-`00027.jpg`); draft, not yet
independently verified by a second pass.
