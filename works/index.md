# Works by Ken Wilber

Index of all known works, one dedicated page per title (`works/<slug>.md`), each with
frontmatter (`title`, `subtitle`, `year`, `format`, `contributors`, `cover`, `core`,
`status`) plus a description and a `## Notes` section reserved for personal
notes/annotations later.

**Cover images are not yet sourced** on any page (`cover: null` everywhere) — see
`docs/plan.md` for the plan to batch-fetch them. Pages with `status: draft` in their
frontmatter have a description that hasn't been verified against a primary source yet.

Format legend: **Book**, **Edited anthology**, **Co-authored book**, **Ebook**, **Audio program**.
★ marks the works flagged `core: true` — the major/load-bearing titles for the theory,
first candidates for their own deep-dive/annotatable treatment (see `docs/plan.md`).

## Notes on sourcing and gaps

- Primary sources cross-checked: [Wikipedia — Ken Wilber](https://en.wikipedia.org/wiki/Ken_Wilber),
  [The Ken Wilber Fund — Books by Ken Wilber](https://www.kenwilberfund.org/books-by-ken-wilber/).
  Ken Wilber Fund's list is well-curated but stops around 2014; everything from 2015
  onward is sourced from Wikipedia alone and should be double-checked against a
  publisher catalog (Shambhala) or [Integral World's bibliography](https://www.integralworld.net/bibliography.html)
  (fetch 503'd during the first pass on this — worth retrying).
- Not included yet: standalone forewords/introductions Wilber wrote for other authors'
  books, journal articles (*ReVision* and elsewhere), and the *Collected Works of Ken
  Wilber* multi-volume set (Shambhala), which repackages earlier books rather than being
  new works — worth a short note on this page rather than separate entries.
- Cover art: none sourced yet. Plan is to batch-fetch via Open Library Covers API
  (by ISBN) or Google Books API, falling back to manual sourcing for older/rare titles
  where API coverage is thin.
