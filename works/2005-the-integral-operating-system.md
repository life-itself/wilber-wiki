# The Integral Operating System

**Year:** 2005 · **Format:** Multimedia course with printed primer


> The package is identified; its complete contributor credits remain to be checked.

## Description

A multimedia introduction to the integral model, published by Sounds True. The
[Ken Wilber Fund catalog](https://www.kenwilberfund.org/books-by-ken-wilber/)
describes a 69-page AQAL primer with a DVD and two audio CDs. Sounds True describes
it as a [course](https://www.soundstrue.com/a/resources/contributor/ken-wilber/),
so it should not be mistaken for another standalone theory book.

[Adam Leonard's publisher biography](https://www.shambhala.com/authors/g-n/adam-leonard.html)
credits him as a co-author of the 2005 package. This is a contributor credit, not a
verified complete list of everyone involved.
